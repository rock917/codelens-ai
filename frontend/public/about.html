Understand your code with CodeLens AI

Explore a repository, find relevant code, and ask questions about how it works.

CodeLens AI is an independent developer project maintained by rock917. It helps developers learn and navigate codebases with source analysis and AI assistance.

What you can do

  • Import a public GitHub or GitLab repository, or upload a ZIP of code you are authorized to process.
  • Browse source files and symbols, search by meaning, and inspect code-analysis findings.
  • Ask questions about the repository and generate suggested documentation and tests.

CodeLens AI is in early access. AI output may be incorrect. The account-free demo should be treated as a shared workspace: use public or non-sensitive sample code. Do not upload credentials or confidential material.

Account sign-in

When enabled, email/password, Google, or GitHub sign-in identifies your account and connects you to your saved workspace. Google sign-in uses basic identity information; CodeLens AI does not request Gmail, Drive, or Calendar access. Provider sign-in availability depends on the current release.

How your code is processed

The backend parses source files and creates a searchable vector index. AI features send your questions and relevant code to Groq for inference. Read the Privacy Policy before submitting code, and review the Terms of Service.
